# Contributing to AuraCam

Thank you for your interest in contributing to **AuraCam**!

## Development Setup

```bash
git clone https://github.com/<your-username>/auracam-majestic-pose.git
cd auracam-majestic-pose
npm install
npm run dev
```

## Build Verification

```bash
npm run build
```

## Code of Conduct

Please adhere to our [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.
